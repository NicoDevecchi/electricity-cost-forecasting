# Electricity Cost Forecasting (Argentina)

Time series forecasting project focused on estimating the average cost of electricity in Argentina using historical data. The project applies statistical analysis and forecasting techniques to model trends and patterns in energy costs.

The workflow includes data preprocessing, exploratory analysis, feature engineering for time series, and model evaluation. The objective is to support better economic and financial analysis related to energy costs.

This project was developed as part of the Data Science and Advanced Analytics diploma at UTN and was commissioned by a real company as an applied case study for data science students.
